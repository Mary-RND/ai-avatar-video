# Кейсы и рынок

## Кейс 1. Цифровой двойник по фото

| Параметр | Значение |
|---|---|
| Задача | показать, что видео можно выпускать без съёмок и студии |
| Аватар | клонированный, собран по фотографии |
| Голос | клон голоса владельца |
| Формат | 9:16, 1080×1920, 25 fps, H.264 CRF 18 |
| Длительность | 29,2 с |
| Время работы | около 2 часов после настройки аватара |
| Цена для клиента | 5 000–10 000 ₽ |

**Что сделано:** аватар собран по фото, голос клонирован по записи, липсинк проверен на
тестовых текстах (фрикативы и взрывные звуки), смонтирован демо-ролик с музыкой и титрами,
экспортированы 1080p и лёгкая 720p.

**Результат:** клиент вводит текст и получает видео. Съёмки нет, стоимость ролика падает
в 3–4 раза по сравнению с видеопродакшном.

## Кейс 2. Конвейер «текст + окружение → видео»

| Параметр | Значение |
|---|---|
| Задача | отдать клиенту инструмент, а не один ролик: сам вводит текст — получает видео |
| Аватар | клонированный + клон голоса, настройка в аккаунте клиента |
| Формат | 9:16, 1080p, версии с фоном и на условно чистом фоне |
| Длительность | 49,4 с с заставкой |
| Время работы | около 3 часов |
| Цена для клиента | 10 000–15 000 ₽ за настройку |

**Что сделано:** клон аватара и голоса, регламент «текст → видео», две версии фона,
монтаж с заставкой, экспорт 1080p и 720p.

**Особенность:** запрос «не шаблон HeyGen» закрывается только персональным клоном —
шаблонные ведущие узнаваемы и убивают доверие.

## Кейс 3. Серия роликов под бренд

| Параметр | Значение |
|---|---|
| Задача | серия роликов 20–60 с в едином фирменном стиле |
| Аватар | клонированный ведущий + фирменная упаковка |
| Формат | 9:16, 1080×1920, заставка + оверлей + грейд + музыка |
| Длительность | 41,9 с (ролик 4 серии) |
| Время работы | около 6 часов, включая заставку и оверлей |
| Цена для клиента | ≈ 3 500 ₽ за ролик в серии (от 35 000 ₽ за 10) |

**Что сделано:** заставка «волшебная ИИ-лаборатория» (4 с), фирменный оверлей (рамка, шапка
с брендом, частицы), лёгкий грейд, музыка с нарастанием 10 → 20 % и затуханием 5 с,
превью и раскадровка, экспорт 1080p + 720p.

**Почему это сильный кейс:** виден полный цикл — от сценария до упаковки, и шаблон
масштабируется на следующие ролики без переделки.

| 4 | FL.ru: три новогодних видео с Дедами Морозами | по договорённости | Ямал Ири, Кыш Бабай, Талви Укко, три голоса | стилизованный |
| 5 | FL.ru: реклама с аватаром заказчика | по договорённости | ролик по сценарию + образец голоса, далее регулярно | клонированный |

Выводы:

1. Два устойчивых типа спроса: «сделайте инструмент» (аватар + голос + самообслуживание)
   и «сделайте ролик/серию».
2. Клонированный аватар просят там, где человек — лицо бизнеса; стилизованный — где персонаж.
3. Почти ни в одном заказе не указаны формат кадра, длительность, площадка и права на
   исходники. Отклик, который сам поднимает эти вопросы, выглядит профессиональнее массы.
4. Бюджеты: 1 500–5 000 ₽ — массовые разовые ролики; 10 000–15 000 ₽ — персональный
   аватар и пакеты.
